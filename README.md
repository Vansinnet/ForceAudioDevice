# ForceAudioDevice

A Darktide Mod Framework mod that selects a configured audio output on startup, supports manual application and fallback to the system default, and can synchronize Darktide's audio setting.

## Installation

Install DMF, place the `ForceAudioDevice` folder in Darktide's mods directory, and add `ForceAudioDevice` to `mod_load_order.txt`.
